## Featured Projects

### 🥗 [Personal Bowl Chef](https://github.com/AndrewRazy/personal-bowl-chef)
`Next.js` · `React` · `JavaScript` · `Ollama` · `Zod`

An interactive digital bowl where you drag and drop ingredients to visualize a meal, then a remote LLM generates a personalized healthy recipe in real time.

- Full-stack app: Next.js backend serving an Ollama REST API, React frontend
- Prompt engineering layer with a constrained system prompt enforcing healthy cooking techniques and food-safety warnings (e.g. temperature requirements)
- Two-layer validation pipeline using **Zod** to type-check LLM output against a strict recipe schema, with an automatic single retry before surfacing an error
